Peripherals and registers¶

This page covers the SoC’s small peripherals (the UART, the timer and the SoC control registers) and then lists the software-visible register pages and the host launch locations, one page at a time.

Related notes: SoC, Interconnect and clocks and Memory.

UART endpoint: rtl/periph/axi_lite_apb_uart.sv¶

PULP’s AXI-Lite-to-APB bridge expects a write address and write data together, while AXI-Lite lets AW and W arrive independently. The ORCA wrapper adds two holding registers, aw_q and w_q, plus valid bits. It accepts whichever channel arrives first, refuses a second copy, and presents both saved channels to the bridge once both exist. It clears the valid bits only when the bridge accepts the pair. Read and write responses otherwise pass through with normal AXI backpressure.

The APB bridge decodes the UART page and drives one apb_uart_wrap. That vendored wrapper converts APB to OBI and contains the PULP UART. Modem inputs are tied inactive and unused modem outputs are left open. rx_i, tx_o and the combined UART interrupt are the only functional external signals. Reset clears the two AXI write-channel holding registers, and the PULP blocks receive the inverted active-low reset.

FIFO and line-status behavior come from the vendored UART, except that the transmitter is ORCA’s fork, rtl/periph/obi_uart_tx.sv. The fork fixes the THRE and TEMT status flags, which the vendored transmitter reports stale (with FIFOs off, a polling writer loses bytes). uart_tb checks both modes.

soc.sv instantiates the wrapper twice. u_uart (base UART_BASE) is ORCA’s console. u_host_uart (base HOST_UART_BASE, 0x8000_4000) is the host side of an on-chip null modem: each UART’s TX drives the other’s RX (ORCA’s RX is the AND of that and the uart_rx pin), so the PS relays the console through the host aperture with no pins. See the console null modem.

Timer endpoint: rtl/periph/axi_lite_mtime.sv¶

The timer is handwritten, because its state is small:

  • mtime_q is a 64-bit counter incremented each SoC clock;

  • mtimecmp_q is a 64-bit compare value;

  • msip_q[0] is the software interrupt level; and

  • mext_q[0] is an external-interrupt validation level.

Like the UART wrapper, it captures AW and W separately. write_fire becomes true once both are saved and there is no older B response. Byte strobes merge only the selected bytes. One B response and one R response can be held under backpressure. Reset clears the request and response state and the interrupt levels, resets mtime to zero, and sets mtimecmp to all ones so the timer interrupt starts inactive. Machine interrupts below gives each offset and its exact behavior.

Both generated register blocks save independent AW/W channels, arbitrate reads against writes, translate byte strobes into per-bit masks, and hold up to two ordered read or write responses. Software-writable fields are flip-flop state with the RDL reset value. Hardware-readable status fields are direct readback from each wrapper’s hwif_in struct. FIN uses its start write indication; the SoC wrapper instead uses the stored cpu_run and cpu_stop levels.

rtl/periph/soc_csrs.sv supplies live stopped/running/performance values and passes the stored run/stop, entry, argument, and generation fields outward. A write of control = 1 runs and clears stop; control = 2 stops; reset is stopped. The generated module sees only six low address bits. The SoC CSR page below lists the exact connections, including every tied-off status field.

FIN’s generated module uses seven low address bits. The handwritten rtl/accel/fin_csrs.sv adapter and the rest of FIN are explained on the FIN accelerator page.

The translation is combinational and is applied to AW and AR independently. All other AXI fields, including ID, burst length, size, strobes, and response backpressure, pass through unchanged. Software must begin and end a burst in one legal aperture window.

0xa400_0000 is the PS physical base assigned in the integrated block design. It is not an RTL constant: orca_pl_top consumes aperture offsets, and Vivado’s address editor supplies the physical address. The host tool keeps --base configurable for temporary /dev/mem use.

The raw-tile registers occupy 0x700 to 0x71c. Tiled-job inputs occupy 0x720 to 0x758, and completion/error/counter outputs occupy 0x75c to 0x77c. Every field and its meaning is described on the FIN accelerator and Hardware tiling pages.

rtl/periph/peakrdl/fin/fin.rdl is the editable SystemRDL source. fin_regs.sv is the generated AXI-Lite storage/decode block, and fin_regs_pkg.sv contains its typed hardware interface. Those generated files use seven address bits because the register region is 128 bytes. The thin rtl/accel/fin_csrs.sv wrapper supplies the page-relative low bits and converts the generated structs to FIN control records.

UART page: 0x8000_1000¶

rtl/periph/axi_lite_apb_uart.sv sends this page through PULP’s axi_lite_to_apb, apb_to_obi, and obi_uart blocks. The wrapper preserves independent AXI-Lite AW and W handshakes by saving whichever channel arrives first. Hardware flow-control inputs are tied inactive; UART RX and TX are the only serial signals exposed by the SoC. orca_pl_top ties RX to idle high and exports TX.

The UART’s internal register map belongs to the vendored PULP UART IP rather than an ORCA-generated CSR block.

Other CLINT offsets read zero and ignore writes, and the external test level exists only in the 0x8000_2000 page. mtime_tb checks both views against each other, and clint_test takes a software and a timer interrupt through the CLINT page only. The core also reads mtime through the read-only time and timeh CSRs.

mtime increments once per SoC clock. A same-cycle software write replaces the selected half after that default increment is calculated. The timer IRQ is high whenever unsigned mtime >= mtimecmp. Byte strobes work on every register, and only bit zero is retained in msip and the external-level register.

axi_lite_mtime saves AW and W independently, permits one write response and one read response at a time, and holds R and B valid until the initiator accepts them. Defined and undefined offsets both return OKAY. Undefined reads return zero and undefined writes do nothing. In the 0x8000_2000 page the decoder uses address bits [4:2], so software must use only the six offsets above and cannot rely on what the rest of the 4 KiB page does.

SoC CSR page: 0x8000_3000¶

rtl/periph/peakrdl/soc/soc.rdl defines this block. PeakRDL generates soc_regs.sv, which implements AXI-Lite channel capture, register storage, decode, and a two-entry response queue, plus soc_regs_pkg.sv, which defines the hardware-facing structs. rtl/periph/soc_csrs.sv connects those structs to the SoC.

This matters for host software: completion does not arrive through the done_id or mailbox CSRs. The boot stub writes the completed run_id to DMA address 0x0000_bff8 and the payload’s return value to 0x0000_bffc, and the host polls and reads those two memory words.

PeakRDL accepts AW and W independently, balances reads against writes, allows up to two transactions in its response queue, and holds responses under backpressure. Byte strobes become a 32-bit write mask. The generated block returns OKAY even for an undefined local offset, where reads are zero and writes have no effect. soc_csrs.sv passes only address bits [5:0], so software must use the named addresses, and higher offsets in the page can alias the 64-byte register region.

Console null modem: 0x8000_4000¶

ORCA’s console is the 16550 at 0x8000_1000 (the PULP UART with ORCA’s transmitter fix). A second instance of the same UART sits at 0x8000_4000, reachable by the PS at host offset 0x14000. Their serial lines cross on chip. ORCA’s TX drives the host UART’s RX, and the host UART’s TX drives ORCA’s RX (ANDed with the uart_rx pin, so either idle-high source can send). ORCA’s TX also leaves on the uart_tx pin. The PS relays the console by polling the host UART through the aperture (scripts/board/orca_host.py --console, class HostConsole), so the board needs no serial pins or adapter. Both ends must use the same divisor; the host tool derives it from --core-hz and --baud. make demo-host DEMO=echo checks the round trip in simulation (prompt, typed line, echo) and the hello demo checks the relay alongside the pin.
