ISA and Software Contract¶

ORCA implements RV32IMA_Zicsr_Zifencei in machine mode, with the user mode that no-MMU Linux requires.

Machine State¶

csr.sv implements mstatus, misa, mie, mip, mtvec, mscratch, mepc, mcause, mtval, the 64-bit cycle and instret counters with read-only user aliases, and read-only zero ID registers. Trap entry uses direct mode, with software, timer and external interrupts. Field details are in the CSR bank table.

User Mode¶

No-MMU Linux runs user code in U-mode and issues system calls with ECALL (cause 8).

  • MPP holds 00 or 11.

  • A trap saves the previous privilege and enters M; mret returns to MPP and sets it to U.

  • In U-mode, machine CSRs and mret are illegal; cycle, time and instret remain readable.

  • Machine interrupts stay enabled in U-mode.

  • No PMP, MPRV or mcounteren, so U-mode provides no protection boundary.

Timer¶

The SoC provides a memory-mapped 64-bit mtime and mtimecmp, a software interrupt bit and external sources (memory lists the addresses). time and timeh read mtime one cycle late, and writes to them are illegal.

Unsupported¶

Supervisor mode, MMU, PMP, delegation, compressed, floating point and vector. Implemented trap causes are on the traps page.

Software¶

The code under sw/ is freestanding: startup code, a linker script, UART output, counter helpers and small demos, with no hosted C library. sw/linux holds the no-MMU Linux tree. Programs start through the boot ROM.

Compliance¶

All 67 official architecture tests pass (RV32I, M, Zaamo, Zalrsc, Zicsr, Zifencei, ExceptionsSm and InterruptsSm) in simulation and on the board, against a Sail model configured for ORCA: one-word reservation granule, trapping misaligned atomics, and no misaligned access support, so those tests are deselected. This is test evidence, separate from RISC-V International certification.
